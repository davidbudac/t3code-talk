# T3 Code

Coordinating agents across harnesses and machines.

A 20-minute talk by David Budac, presented on 3 November 2026. Fifteen slides, excluding Q&A.

Download or clone this repository and open [presentation.html](presentation.html) in a browser. Keep `assets/` and `fonts/` beside it. The deck works offline.

Use the arrow keys, Space, or Page Up / Page Down to move through the slides and reveals. Home and End jump to the first and last slides. The dots on the right jump to a slide; scrolling and swiping also advance the deck.

[slides.md](slides.md) contains the slide text. The HTML deck includes the diagrams, screenshots, and animations.
