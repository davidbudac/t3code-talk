Code15 / 15

What to take home

  1. One inbox

    Threads fold away while they work and come back when they need you. A merged PR closes its thread.

  2. Any machine

    Every box runs a T3 Code server. Pick one when you start a thread, from desktop, web or phone. Machines can call each other.

  3. Any harness

    Claude Code, Codex, Cursor and the rest, with your own logins. A thread can delegate to another harness and get findings back.

Try it this week
1Install on your laptop and on one other box, then run t3 up over there
2Send one real task to the other box. Ask the thread to have a second harness review the diff
3Open the PR, close the laptop. Check the inbox tomorrow.
